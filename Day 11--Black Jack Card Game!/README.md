# Blackjack 🃏

## About the Project

A beginner Python Blackjack game where the player competes against the computer. The game deals random cards, calculates scores, handles Blackjack and Aces, and determines the winner.

## How It Works

* The player and computer receive two cards.
* The player can choose to draw another card or pass.
* The computer draws cards until reaching a score of at least 17.
* The program compares both scores and determines the winner.
* The player can choose to play again.

## How to Run

```bash
python main.py
```
