# Roller Coaster Ticketing 🎢

A beginner Python project that simulates a roller coaster ticketing system.

The program checks the user's **height and age** to determine whether they can ride and how much their ticket costs. It also gives the option to purchase a ride picture.

## How It Works

* Checks if the rider meets the minimum height requirement.
* Determines the ticket price based on age.
* Riders aged 45–55 get a free ticket.
* Gives the option to add a picture to the ticket.
* Displays the final price.

## How to Run

```bash
python main.py
```

## What I Learned

* `if`, `elif`, and `else`
* Comparison operators
* Nested conditionals
* User input
* Variables
* Basic calculations
* Boolean conditions



# Pizza Order Calculator 🍕

A beginner Python project that calculates the price of a pizza based on its size and selected toppings.

## How It Works

* Choose a pizza size: Small, Medium, or Large.
* Choose whether to add pepperoni.
* Choose whether to add extra cheese.
* The program calculates and displays the final bill.

## How to Run

```bash
python main.py
```

## What I Learned

* `if`, `elif`, and `else`
* Conditional statements
* User input
* Variables
* Arithmetic operations
* Building a simple ordering system



# TREASURE ISLAND 🏝️

A beginner Python text-based adventure game where the player makes choices to find a hidden treasure.

## How It Works

The player makes a series of decisions:

* Choose to go left or right.
* Choose whether to swim or wait.
* Choose between three doors.
* Different choices lead to different endings.

## How to Run

```bash
python main.py
```

## What I Learned

* `if`, `elif`, and `else`
* Nested conditional statements
* User input
* String methods
* `.lower()`
* Building a simple text-based game
