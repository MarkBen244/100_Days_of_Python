# Password Generator 🔐

A beginner Python program that generates a randomized password based on the number of letters, numbers, and symbols requested by the user.

## How It Works

* Choose the number of letters.
* Choose the number of numbers.
* Choose the number of symbols.
* The program randomly selects the characters and shuffles them to create a password.

## How to Run

```bash
python main.py
```
