# Coin Toss 🪙

A simple Python program that randomly simulates flipping a coin and prints either **Heads** or **Tails**.

## How to Run


python main.py

* Generating random numbers

# Rock Paper Scissors 🪨📄✂️

A simple Python Rock Paper Scissors game where the player competes against a randomly generated computer choice.

## How It Works

* Choose Rock, Paper, or Scissors.
* The computer randomly selects its choice.
* The program compares both choices and determines the winner.

## How to Run

```bash
python main.py
```

## What I Learned

* Lists
* `if`, `elif`, and `else`
* Random numbers
* User input
* Conditional logic
* Basic game logic
