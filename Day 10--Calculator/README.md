# Python Calculator 🧮

## About the Project

A beginner Python calculator that performs basic arithmetic operations and allows the user to continue calculating with the previous result or start a new calculation.

## How It Works

The calculator supports:

* Addition
* Subtraction
* Multiplication
* Division
* Continuing with the previous result
* Starting a new calculation
* Ending the program

## How to Run

```bash
python main.py
```
