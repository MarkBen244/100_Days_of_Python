# 🐢 Turtle Race

## About the Project

Turtle Race is a simple Python racing game built using the `turtle` graphics module.

The player chooses which colored turtle they think will win the race. Six turtles then race across the screen, with each turtle moving a random distance on every turn. The first turtle to cross the finish line wins.

This project helped me practice working with Python objects, lists, loops, conditionals, user input, and the `turtle` module.

## Features

* 🐢 Six racing turtles
* 🎨 Different colors for each turtle
* 🎯 Player can bet on a turtle
* 🏁 Randomized turtle movement
* 🏆 Automatic winner detection
* ✅ Win/loss result
* 🖥️ Interactive graphical interface

## How It Works

1. A turtle racing window is created.
2. The player is asked to choose a turtle color.
3. Six turtles are placed at different starting positions.
4. Each turtle moves a random distance between 0 and 10 pixels.
5. The race continues until one turtle crosses the finish line.
6. The winning turtle's color is compared with the player's bet.
7. The program displays whether the player won or lost.

## How to Run

Make sure Python is installed on your computer.

Run the program from the project directory:

```bash
python main.py
```

A graphical window will open and you can place your bet.
