# Pomodoro Timer

## About the Project

A simple Pomodoro Timer built with Python and Tkinter to help improve productivity and time management.

The timer follows the Pomodoro Technique, alternating between focused work sessions and short breaks, with a longer break after four work sessions.

### Features
- 25-minute work sessions
- 5-minute short breaks
- 20-minute long breaks after four work sessions
- Start and reset buttons
- Visual countdown with a tomato image
- Checkmarks to track completed work sessions
- Automatic timer cancellation when resetting

### Technologies Used
- Python
- Tkinter
- `pathlib`
- `math`

### How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository or download the project files.
3. Ensure `main.py` and `tomato.png` are in the same folder.
4. Open a terminal in the project folder.
5. Run:

```bash
python main.py
```
