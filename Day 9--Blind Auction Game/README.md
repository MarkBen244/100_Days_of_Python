# Silent Auction 💰

A beginner Python program that simulates a silent auction. Multiple players can enter their names and bids, and the program determines the highest bidder.

## How It Works

* Players enter their name and bid.
* Bids are stored in a dictionary.
* Players can continue entering bids.
* When the auction ends, the program finds and displays the highest bidder.

## How to Run

```bash
python main.py
```
