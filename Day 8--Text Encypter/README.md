# Caesar Cipher 🔐

A beginner Python program that can encode and decode messages using the Caesar cipher.

## How It Works

* Enter a message.
* Choose `encode` or `decode`.
* Enter a shift number.
* The program shifts each letter through the alphabet.
* The program allows you to encode or decode another message.

## How to Run

```bash
python main.py
```
