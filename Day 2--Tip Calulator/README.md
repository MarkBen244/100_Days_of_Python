# Python Tip Calculator 💰

My first Python project. A simple program that calculates how much each person should pay when splitting a restaurant bill, including a tip.

## How It Works

The program asks for:

* Total bill
* Tip percentage
* Number of people

It then calculates the total bill with the tip and splits it between everyone.

## How to Run

```bash
python main.py
```
